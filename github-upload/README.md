# AI in Pharma: From Experimentation to Transformation

A visual report by Stefan Schwarzfischer, CEO, PharmaLedger.

Research cutoff: 23 October 2026. Outlook to October 2027.

## Files

- `index.html`: the complete report, including all five embedded images, styling, interactive controls and source references.
- `social-preview.png`: the cover artwork used for link previews on LinkedIn and other social platforms.
- `.nojekyll`: tells GitHub Pages to serve these files directly. No build is required.
- `README.md`: these instructions.

## Upload to GitHub

1. Unzip the download on your computer.
2. Open https://github.com/Stefan2206/pharma-ai-report.
3. Choose **Add file → Upload files**, or **uploading an existing file** if the repository is empty.
4. Upload the extracted files into the repository root, so that `index.html` appears directly in the main file list. Do not upload the ZIP itself or put the files inside an extra folder.
5. Commit the changes to the `main` branch.
6. Open **Settings → Pages**. Select **Deploy from a branch**, then **main** and **/ (root)**, and save.
7. Wait for GitHub to report that deployment has completed, then open the address below and check the report before sharing it.

If your file picker hides `.nojekyll`, you can create an empty file with that name using GitHub’s **Add file → Create new file**. The plain HTML report can also be served by GitHub Pages without it.

Expected public address after successful deployment:

https://stefan2206.github.io/pharma-ai-report/

With GitHub Free, the repository must be public to use GitHub Pages.

## LinkedIn sharing

Share the public GitHub Pages address, rather than the repository address or a local file link. Link-preview metadata is included in `index.html` and points to `social-preview.png` in this repository. LinkedIn may cache previews; its Post Inspector can request a refresh after the site is live:

https://www.linkedin.com/post-inspector/

## Updating the report

Replace `index.html` with an updated version and commit the change. Replace `social-preview.png` as well if the cover artwork changes. No Node.js, packages, server or build command is needed.
